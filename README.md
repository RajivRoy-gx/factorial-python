Python Factorial

A simple Python program to calculate the factorial of a given non-negative integer.

Features
Calculates the factorial of a number.
Simple and beginner-friendly Python code.
Handles non-negative integers.
How Factorial Works

The factorial of a non-negative integer n is the product of all positive integers from 1 to n.

For example:

5! = 5 × 4 × 3 × 2 × 1 = 120


Also:

0! = 1

Requirements
Python 3.x
Usage

Clone the repository and run the Python program:

python factorial.py


Enter a non-negative integer when prompted.

Example
Enter a number: 5
Factorial of 5 is 120
